# BrainLab｜认知游戏研究与设计

以经典益智游戏为入口，建立可解释、可测量、可迭代的认知游戏项目。当前版本：v0.1（2026-10-09）。

## 使用

下载 `index.html` 后在浏览器打开。页面包含 15 个游戏任务、9 类认知能力、规则说明、可筛选的任务需求矩阵、脑区功能关联和研究路线图。全部样式与脚本内嵌，无运行依赖，可离线访问。

公网页面：[https://qc0317.github.io/brainlab/](https://qc0317.github.io/brainlab/)

GitHub Pages 从 `main` 分支根目录自动发布。更新 `index.html` 并提交后，公网页面会自动重新部署。

## 目录

- `index.html`：单页项目设计文档。
- `data/project-data.json`：游戏与矩阵的数据快照，便于分析和跨环境复用。
- `research/sources.md`：参考资料与适用边界。
- `research/roadmap.md`：后续研究工作。
- `CHANGELOG.md`：版本变更。

## 编辑

当前页面以 `index.html` 内的 `projectData` 为数据源。更新它会同时更新游戏卡片与矩阵；修改后应同步 `data/project-data.json`，该 JSON 不会自动加载。需求值 2 / 1 / 0 分别表示主要、次要或条件相关、未列为突出需求。

新增游戏需补全规则、版本说明及九项需求值；新增能力时要同步所有游戏的需求数组。静态章节、样式与脚本均位于同一 HTML 文件，搜索章节 id 即可定位。

## 科学边界

矩阵描述任务需求，不是训练效果评级。游戏成绩改善不能直接证明近迁移、远迁移或特定脑区强化。脑区表是功能关联概览，不是游戏脑成像证据。当前没有逐款游戏的系统证据审查。

黑白翻转和堆叠水果采用明确标注的工作定义；密室逃脱需进一步指定作品与单个关卡。原讨论中的其他模糊游戏名称保存在页面待澄清清单。

## 资源约定

研究资料优先保存链接、书目信息和自主撰写的摘要。外部全文、图像或游戏素材应在确认许可后加入仓库，并记录出处与许可。当前未指定本项目的开放许可。
