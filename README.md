# BrainLab｜认知健康研究知识库

以日常游戏与多领域活动支持认知健康，探索功能维持与风险降低的可行路径。首阶段面向认知基本正常的中老年人。**尚未验证本产品的认知或预防疗效。**

- 公网阅读：[BrainLab](https://qc0317.github.io/brainlab/)
- 本期：v1.0（2026-10-09），59 个知识/设计条目，36 项来源，72 个生成页面。
- GitHub 管理的结构化知识库：多级页面、全文检索、来源与关系反向链接；暂不做在线编辑、账户和个人健康数据后台。

## 编辑与构建

唯一当前内容来源为 `data/knowledge.json`。记录包括稳定 id、专题、标题/摘要、状态、章节、引用、带类型关系；游戏还包括规则版本与需求。编辑章节与 `relationships`，生成的 HTML 不直接编辑。`data/project-data.json` 为 v0.3 迁移输入，仅保留历史，不再作为当前页面内容来源。

```sh
python3 scripts/build.py
python3 scripts/validate.py
git diff
git add .
git commit -m "Update knowledge base"
git push origin main
```

Python 3.9+，仅标准库；无 Node/npm 构建依赖。页面使用原生 CSS/JS，无外部字体、跟踪器或服务依赖。检索数据内嵌至本地 JS，下载整个仓库后也可直接打开 `index.html` 浏览。`data/search-index.json` 和 `data/build-manifest.json` 为生成文件。

`data/schema.json` 描述内容字段。构建检查 id、引用、关系和需求完整性；验证脚本检查生成页面、全部本地链接/锚点、检索覆盖和矩阵映射。加入新专题时更新 JSON 的 `collections`。加入新条目时遵循同一字段结构，执行两项检查后提交。

GitHub Pages 从 `main` 根目录发布；`.nojekyll` 保留原生静态路径。旧单页章节链接映射到新目录；`archive/v0.3.html` 保留历史单页。旧 `research/*.md` 是历史资料，不再代表最新版本。

## 研究状态与观察范围

这是较深入的专题叙述性研究与设计基线，尚未完成完整系统检索、所有全文提取、偏倚评估或专家审稿。每个来源记录类型、年份、读取范围和局限；摘要/官方概要不会标为已完成全文审查。积极和相反证据并列。

多邻国采用官方产品/设计资料与历史首页图；Keep 实际观察公开 Web 课程目录与一个详情样本。**未实测原生 App、跟练、AI、通知、订阅和完整用户旅程。**截图只作有限研究样本，原界面版权归原权利人；见页面说明与来源。产品建议和黏性分析是待检验假设。
