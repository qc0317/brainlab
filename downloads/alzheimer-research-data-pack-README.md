# BrainLab 阿尔茨海默病结构化研究材料包

这是 BrainLab 阿尔茨海默病专题的结构化研究材料包，适合跨端下载、检索和复盘。

## 包含内容

- `data/alzheimer/trial-extractions.json`：逐篇研究提取记录，包括人群、干预、对照、结局层级、效应条目、访问范围和方法学待核项。
- `data/alzheimer/evidence-synthesis-matrix.json`：按任务、认知、功能、临床痴呆和AD特异性边界组织的综合矩阵。
- `data/alzheimer/evidence-extraction-coverage.json`：字段覆盖与未完成边界审计。
- `research-programs/alzheimer/PROTOCOL.md`：计数口径、终点升级规则和方法学评估协议。
- `research-programs/alzheimer/TRIALS.md`：研究对照表。
- `research-programs/alzheimer/AUDIT.md`、`DELIVERY-AUDIT.md`、`EDITORIAL.md`：编辑、交付和剩余工作记录。

## 解释边界

材料包不包含完整 HTML 站点，也不把来源列表或代码计入十万字正文。当前逐篇记录多数仍是部分提取，正式 RoB2、ROBIS、ROBINS-I 和 GRADE 裁决仍在继续。任务或认知改善不能直接解释为阿尔茨海默病预防。
