多邻国官方网页实时观察记录

观察元数据

  • 观察日期：2026-10-12
  • 入口：<https://www.duolingo.com/>
  • 语言：中文站点
  • 平台：桌面 Web
  • 登录状态：未登录
  • 证据类型：公开网页实时可见内容
  • 观察限制：未进入账号内课程、未提交注册、未授权通知或麦克风，不能据此判断登录后 App 的全部功能。

首页实时可见的产品承诺

当前中文官网首屏将产品表达为“开开心心学语言，国际象棋等学科”，并提供开始注册和已有帐户入口。页面将学习描述为每天几分钟、完成小单元、获得经验和闯关升级，明确把课程学习包装成轻量、游戏化和可连续开始的行为。

页面公开展示三类价值说明：

1. **教学科学有效**：课程以语言科学和研究为依据，目标覆盖听、说、读、写； 2. **学习动力满满**：小挑战、游戏化、吉祥物和提醒帮助用户建立日常习惯； 3. **课程量身定制**：页面声称结合 AI 和语言科学，根据语言水平和学习步伐提供个性化体验。

当前中文官网列出的课程入口

在未登录首页的课程列表中，当前可直接看到以下入口：英语、国际象棋、西班牙语、法语、德语、意大利语、葡萄牙语、日语、韩语和中文（粤语）。这些是中文官网当时公开展示的入口，不代表所有语言方向、所有学科或所有国家版本的完整目录。点击英语课程入口后，未登录状态没有呈现完整课程树，因此 Section、Unit、Level 和 Lesson 仍需账号内观察。

这些是官方产品承诺，不等于本研究已经独立验证其效果。研究记录必须把“页面如何宣传”与“用户是否真正获得能力提升”分开。

首页公开信息架构

未登录首页的公开导航把入口分成：

  • 课程；
  • 我们的使命、教学方法和有效性；
  • 研究、文化手册和招聘；
  • 宝石小店；
  • 多邻国、Schools、英语测试、播客、Business、Super、Gift、Max；
  • App 下载；
  • 帮助与客服、状态、社区守则、条款和隐私；
  • 网站语言切换。

这说明官网的公开信息架构已经把产品本体、教学证据、商业服务、支持系统和公司研究分开。登录后 App 的底部导航不能直接从官网页脚推断，但官网提供了下一步研究入口。

公开首页到产品系统的映射

| 官网可见表面 | 可能对应的产品系统 | 当前可确认范围 | |---|---|---| | 每天几分钟、小单元 | Lesson、Daily Goal、Streak | 公开产品承诺；内部规则待测 | | 经验、闯关升级 | XP、Level、Course Progress | 公开表达；计算规则待测 | | 吉祥物提醒 | 角色反馈、通知、召回 | 页面提及；通知频率待测 | | 个性化课程 | 推荐、难度、复习、路径 | 官方宣称；模型和效果待测 | | 宝石小店 | Gems、Shop、道具经济 | 公开入口；当前商品待测 | | Super / Max | 订阅与高级权益 | 公开产品入口；当前权益和价格待测 | | 研究与有效性 | 教学证据和研究叙事 | 公开入口；不能替代独立疗效判断 |

当前网页观察不能证明什么

首页没有登录后的 Section、Unit、Level、Exercise、Hearts、Energy、Quest、League、Feed、Profile、Badge 或具体通知状态，因此这些功能继续保持“需要当前账号实测”。课程目录链接在未登录访问时没有呈现完整课程树，不能把官网营销页当成课程数据库。

下一步实测入口

若获得一个可用的测试账号，优先从首页“开始”进入，记录注册前承诺是否与首课体验一致；再访问课程入口、帮助中心、宝石商店和 Super/Max 页面，保存价格地区、权益和退出路径。所有登录、订阅和权限操作都应在研究授权范围内完成，不把私人账号或支付信息写入研究资料。
