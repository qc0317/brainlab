研究的统一格式

每项机制都按照以下顺序阅读：

1. **产品事实**：页面或官方资料直接显示什么； 2. **结构模型**：它在课程、任务、社交、身份、资源或商业化系统中的位置； 3. **交互状态**：进入、进行中、完成、失败、恢复和退出； 4. **设计推断**：它可能解决什么用户问题； 5. **待验证问题**：需要实测、访谈、行为数据或长期研究回答什么。

当前证据状态

  • 已有官方中文官网的未登录实时观察；
  • 已收录官方产品文章、帮助页面和设计文章作为历史/公开证据；
  • 已建立课程、功能、状态、版本和截图数据结构；
  • 当前登录后 App 的逐屏截图和行为日志仍需账号、平台和版本条件；
  • 任何未实测的当前功能都明确标记为待验证，不假装是完整现状。

BrainLab 的迁移边界

可迁移的是：短时任务、清晰下一步、多时间尺度反馈、可恢复连续性、轻关系协作、可解释状态和结构化事件记录。不能直接复制的是品牌角色、图标、插画、文案、排行榜压力、商业化限制和未经验证的效果承诺。迁移前必须重新定义目标人群、任务能力、隐私和验证指标。
