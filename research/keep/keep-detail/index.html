可确认的选择前信息

所观察目录用课程图片、名称、等级与器械信息帮助用户先判断内容。卡片可以提升浏览速度，也可能在图片复杂、文字叠加时造成识别负担。后一句属于界面分析假设，需要在目标用户上验证。

本项目的会话状态设计

界面用户需要的信息候选操作
任务卡做什么、多久、如何操作预览规则 / 加入今日计划
准备页示范、难度与支持选项先试一题 / 开始
练习页当前任务与进度暂停 / 提示 / 结束
暂停页继续后会发生什么继续 / 调整 / 保存退出
复盘页完成与负荷、具体变化看解释 / 下次安排 / 完成

易用性细节 · 待验证

  • 任务名称尽量是具体动词，例如“记住位置顺序”；脑科学说明放入可选阅读。
  • 操作按钮与素材区保持稳定；减少会话中跨页导航。
  • 同时说明“提示可用”和“结束可用”，防止用户误以为必须全部完成。
  • 数据图说明单位、任务版本、日期与比较条件；不可跨难度直接画认知提升曲线。
  • 完成页默认只要求一次轻量负荷反馈；避免长问卷打断体验。

尚待实测的 Keep 原生流程

首次配置、选择计划、实际跟练、暂停/恢复、完成复盘、推送、数据权限与订阅边界均未实测。下一轮需记录设备、系统、App 版本、地区、账户/订阅状态及实验差异，采用完整任务观察；不能用 Web 目录替代这些步骤。
