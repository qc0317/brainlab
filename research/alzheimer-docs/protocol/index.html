阿尔茨海默病与脑部训练：专题重建研究方案

建立日期：2026-10-09。状态：进行中；上一版专题不视为满足本次需求。

用途：用户个人、非商业研究与多端阅读。优先正文、文献原始数据、许可允许的翻译/双语对照、图表和笔记。网页为阅读载体，产品设计只作为次要附录，不组织成营销页或训练服务。

研究目标

检验“脑部训练对于预防阿尔茨海默病可能有效”。这是待检验的问题，不是需要无条件证明的宣传结论。必须分开判断：AD 特异性发病、全因痴呆、轻度认知障碍、独立认知测验、日常功能、游戏内学习、病理/影像变化。

正文目标不少于 100,000 个中文汉字。读者应先能解释疾病，再能理解原因与表现、脑部改变、训练的可能路径和人类干预证据。材料将组织为四大部分及证据附录；每一部分既有基础解释，也有机制、数据和方法学分析。

四个读者问题

1. 什么是阿尔茨海默病？用生活例子区分正常忘事、MCI、痴呆综合征与 AD 病因，解释病理变化和出现症状为什么不是同一个时间点。 2. 为什么会发病、怎样表现？区分病理机制、遗传原因、风险因素、相关因素；按认知、行为、日常功能与不同表型解释表现，不用单个症状诊断。 3. 脑部发生什么？区分尸检病理、MRI、PET、液体生物标志物、EEG 和认知测验；解释脑区/网络与临床表现的联系以及测量限制。 4. 训练可能有效吗？区分认知训练、认知刺激、康复、技能学习和多领域干预；逐篇提取支持、无效、负面和不一致的结果，再讨论可推广范围。

文献与数据工作流

  • 优先：原始随机对照试验、长期随访、系统综述、诊断标准与专业指南；机制研究分别标记人类观察、动物或细胞模型。
  • 数据库：PubMed/PMC、Europe PMC、Cochrane、论文期刊与研究团队的原始资料、NIH/NIA 等机构说明。
  • 搜索范围：疾病定义/阶段、症状与功能、病理与影像、遗传/感觉/血管/生活方式、认知训练与痴呆发病/认知结果、游戏与任务迁移、长期保持。
  • 每次检索保存日期、检索词、数据库、纳排说明；本次为分阶段、单人辅助的研究综合，不冒称双人独立系统综述。
  • 每篇提取：作者/年份、DOI/PMID/PMCID、注册号、人群、随机/盲法、干预/对照、剂量、随访、主要/次要终点、效应及区间、失访、资金/利益关系、局限与访问范围。
  • 来源无法取得全文时只做摘要级提取；全文与数据表核对完成后再升级状态。摘要中没有的指标不自行补齐。
  • 同一试验的不同年份、亚组、影像与再分析建立共同 trial_id，不当作独立重复证据计数。
  • 不预先赋予 GRADE 等级。偏倚/确定性判断逐维度说明依据；尚未评估的栏目标为未评估。
  • 不为凑字数生成相似段落；长文包含具体的解释、数据审查、因果推断、竞争解释、测量与研究设计分析。

版权与引用

“可在线阅读”不等于“可大规模复制”。核验版权/许可，CC BY 与 CC BY-NC-ND 等区别记录。含 ND 的材料不能因开放获取就直接翻译全文后公开。原始 XML 先存工作目录供核验，未经许可不上传全文。公开专题采用原创中文解释、注明出处的数据提取、许可范围内的材料与合规短引文。

引用接近相关结论；来源说明提供原文链接、访问范围和许可。保留“研究报告”与“本专题解释/推论”的边界，虚构演示例子必须标为说明性例子，不伪装病例或研究数据。

字数验收

以 `data/alzheimer/program.json` 登记的新版正文记录为计数范围；旧未重写条目、代码、标题/导航、来源列表、JSON 字段、英文全文、重复段落、计划标题不计入。仅统计正文汉字，另提供正文可见字符数供参考。相同段落在全专题只计一次；章节正文去重后达到至少 100,000 汉字，再完成引用/数据审核与公开验收，才能把本 GOAL 标记完成。

每章保留正文计数和写作/审核状态。10 万字是交付门槛，不是医学结论有效性的保证。

完成条件

  • 四条由浅入深的阅读路线均完整，基础概念可用例子理解；缩写首次解释。
  • 正文达到上述字数门槛，有实质内容且不重复充数。
  • 重点干预试验及其相反/更新证据有独立提取卡；正向与无效结果并列。
  • 结论区分直接支持、间接支持、尚未验证与反证，保留人群和终点条件。

终点分层与结论门槛

本专题把训练研究的结果按由近及远分为四层，禁止用低层结果替代高层结论：

1. **任务层**：训练过的游戏或测验是否变快、变准，或在相似材料上表现更好。它回答练习和近迁移，不能单独说明一般认知改善。 2. **认知与功能层**：未参与训练的标准化认知测验、日常功能、工具性日常活动或照护需求是否改变。必须说明测验是否独立于训练、效应持续多久以及是否由盲法评估者测量。 3. **临床综合结局层**：MCI、全因痴呆或临床进展是否减少。MCI、全因痴呆和 AD 不能互换；复合终点必须拆开报告。 4. **AD 特异性疾病层**：符合预先定义的 AD 诊断、病理、生物标志物或疾病进展是否改变。影像或标志物变化只有在测量可靠、时间顺序和临床意义明确时，才可作为这一层的证据。

每条研究记录必须同时写出“研究实际测量了哪一层”和“它没有测量哪一层”。只有在目标人群、随机或可识别的比较、预先规定的结局、足够随访和可接受的偏倚控制都成立时，才允许把结果写成对更高层结局的支持。训练任务显著而临床综合结局无差异时，结论应保留为“任务收益”，不能升级成预防痴呆或改变 AD 病程。

个人研究阅读与资料呈现

本资料库首先服务个人跨端阅读、检索和复盘。以问题为入口，将中文解释、原始论文链接、关键数据、读取范围、版本和待核对项放在同一阅读路径中。

翻译材料注明原文位置、译文范围和术语；逐字翻译、概括与研究者解释分别标记。图表注明作者、年份、图号、许可、裁剪或改绘情况，并保留原文入口。可公开复用的材料在许可范围内保存；其他材料提供链接、简短合规摘引与原创解读。个人非商业用途不自动等于公开转载许可。

页面优先支持阅读层级和证据追溯，不用产品推广表达替代研究结论。资料增加后仍保留支持、无差异、反对证据与尚未解决的疑问。

同步生成与离线复盘

知识章节以 `data/knowledge.json` 为正文来源；四步阅读顺序以 `data/alzheimer/program.json` 为准；逐篇对照字段以 `data/alzheimer/trial-extractions.json` 为准。修改这些文件后执行 `python3 scripts/build.py`，会依次重新计数、生成研究对照表、正文下载及离线包，再生成网页与检索索引。

随后执行 `python3 scripts/validate.py` 检查链接、来源、检索目标、结构化字段及离线包完整性。离线包中的文件必须与当前资料逐字节一致，旧包会使校验失败。以上检查不替代科学和可读性审核。

已嵌入材料的定向复核

[图像与短引文记录](../../data/alzheimer/reuse-audit.json)保留两张现有原文图的来源、署名、裁剪说明、许可链接与文件哈希，以及一项明确双语摘引的范围。此记录只覆盖这些材料，不代表全部文献许可、第三方材料或科学事实已审核。

方法学评估矩阵（研究级审核入口）

本专题把“有结果”与“结果可信度”分开。每条记录先按研究设计选择工具，再按结局层级决定能否进入核心问题的综合。当前矩阵是审核协议，不是已经完成的最终评分。

统一记录字段

每个研究条目应分别保存：设计类型、分析人群、随机或比较来源、主要终点、终点层级、效应量及区间、事件数和分母、缺失处理、统计模型、注册/方案版本、访问范围、偏倚判断、确定性判断和“仍不能推断什么”。“风险_of_bias_review”字段若只含待核说明，不能写成低偏倚或高确定性结论。

预防问题的升级规则

从“任务训练有效”升级到“认知迁移”需要独立未训练测验；从“认知迁移”升级到“功能改善”需要日常功能或生态结局；从“功能改善”升级到“痴呆预防”需要预先定义的临床诊断或可靠算法终点、足够随访、可追溯分母和缺失/竞争风险处理；从“痴呆预防”升级到“阿尔茨海默病特异性预防”还需要AD特异性诊断或生物标志物定义。任何一步缺失，都保留在较低层级，不向上推断。

当前状态

截至当前版本，结构化提取覆盖审计显示多数记录仍为部分提取；因此本专题的“证据综合”应使用支持、反证、间接和缺失四类标签，不能使用单一“有效/无效”标签替代方法学判断。正式RoB2、ROBIS、ROBINS-I与GRADE裁决将在逐篇全文和补充材料核对完成后更新。
